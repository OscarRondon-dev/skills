# Seguridad de este sistema

- **`threat-model.md`** — modelo de amenazas **vivo** (qué puede salir mal aquí).
- Los estándares de *cómo* escribir código seguro viven en `docs/standards/security.md` si existen. No mezclarlos.

Actualizar el modelo cuando cambien autenticación, autorización, datos sensibles, límites de confianza o APIs públicas. Usar la skill `threat-modeling` (modos inception / delta / review).
